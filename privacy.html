Pixel Obby Privacy Policy

Last updated: September 1, 2026

Pixel Obby is a browser-based obstacle game. This policy explains what information the game uses and how it is handled.

Guest play

You can play Pixel Obby without creating an account. In guest mode, game progress, XP, unlocked items, and settings are stored locally on your device using browser storage. Guest game-save data is not uploaded as cloud-save data unless you choose the optional “Save Online” feature.

Anonymous product analytics

Pixel Obby collects limited anonymous gameplay analytics to understand whether the game is being used and where the experience needs improvement. The game creates a random visitor identifier in local browser/app storage and a random session identifier. Analytics events may include opening Pixel Obby, starting an obby, completing an obby, the obby number, and whether the experience is running in a browser or standalone/app display mode.

These analytics do not require an account or email address. Pixel Obby does not intentionally include names, email addresses, precise location, contacts, advertising identifiers, or game-save contents in the anonymous analytics event table. Clearing browser/app storage or using a different device may create a new anonymous visitor identifier.

Optional cloud save

If you choose the optional “Save Online” feature, you provide an email address to receive a passwordless sign-in link. Authentication and cloud storage are provided through Supabase. When cloud sync is enabled, Pixel Obby may store your account identifier, email address used for sign-in, game progress, and obby run history so that progress can be used across devices.

How information is used

Anonymous analytics are used to measure usage, game starts, obby completions, and return usage and to improve Pixel Obby. Information used by the optional cloud-save feature is used to authenticate you, synchronize game progress, provide history/export features, and support account or cloud-data deletion. Pixel Obby does not sell personal information and does not use it for advertising.

Third-party services

Pixel Obby is served through GitHub Pages and uses Supabase for anonymous analytics and optional account/cloud-save features. The web app may also retrieve technical libraries through a content delivery network. These providers may process standard network information as part of delivering their services, subject to their own privacy terms.

Data retention and deletion

Guest game-save data remains on the device until you clear the browser/app storage. Anonymous analytics are retained for product measurement until they are deleted or the service is discontinued. If you use cloud save, the account screen provides controls to export history and delete the account and associated Pixel Obby cloud data. Clearing browser/app storage resets the locally stored anonymous analytics identifier but does not retroactively remove previously aggregated analytics events.

Security

Cloud connections use HTTPS. Pixel Obby does not store account passwords; optional sign-in uses an emailed magic link. Public clients can submit limited analytics events but cannot read the raw analytics event table.

Children and family use

Pixel Obby does not require an account to play. If a child uses the optional cloud-save feature, a parent or guardian should manage the email address used for sign-in.

Changes

This policy may be updated when Pixel Obby features or data practices change. The latest version will remain available at this URL.

Privacy questions

For privacy questions or requests, use the project’s public support channel at Pixel Obby GitHub Issues.
